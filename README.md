# 校园笔记 · 项目说明文档

> 一个面向校园的「打卡 + 笔记」小程序：每天打卡养成习惯，随手记录校园生活，还能看到同校同学的公开笔记和打卡排行榜。

---

## 一、这个项目是干什么用的？

### 1. 一句话介绍

**「校园笔记」是一个校园生活小助手**：帮学生坚持每天打卡（早起、自习、运动、读书、喝水），把校园里的事写成笔记（可以公开给同学看，也可以只给自己看），并在校区页查看校区信息和活动。

### 2. 它解决什么问题

| 学生的小烦恼 | 这个小程序怎么帮 |
|---|---|
| 想养成好习惯，但坚持不下来 | 打卡页有大按钮 + 连续天数 + 28 天热力图，看得见自己的坚持 |
| 灵感、笔记散落在各处，找不到 | 笔记列表支持搜索、标签筛选、卡片/列表两种视图 |
| 想看看同学在做什么 | 公开笔记信息流 + 今日打卡排行榜 |
| 不知道校区有什么活动、附近有什么 | 校区页集中展示概况、活动、附近服务 |

### 3. 谁在用

- **学生**：打卡、写笔记、看排行榜、看校区活动。
- **同学之间**：公开笔记互相可见，打卡排行榜按当天打卡次数排名。

### 4. 设计风格

**风格 B：效率笔记风**

- 主色：墨蓝 `#1F3A5F`；辅助色：暖橙 `#C97B4A`（只用于强调）
- 背景：暖白 / 米白 `#F7F4EE`，卡片 `#FFFDF8`
- 卡片少阴影、重分割线，圆角 24rpx
- 标题加粗，正文行高 1.6

## 三、根目录文件逐个说明

### `app.js` —— 小程序的「启动开关」

小程序一打开就先运行它，负责三件事：

1. **初始化云开发**：`wx.cloud.init()`，让页面能读写云数据库。
2. **保存全局数据**：`globalData` 里存当前校区（默认「东湖校区」）和昵称（默认「同学」），所有页面都能读到。
3. **提供两个公共方法**：
   - `setCampus(name)`：切换校区，同时写进本地存储，下次打开还记得。
   - `setNickName(name)`：修改昵称，同样本地保存。
4. 另外设置了默认的「分享给朋友」内容。

### `app.json` —— 小程序的「总目录」

- `pages`：登记全部 6 个页面，**第一个就是启动页**（首页）。
- `window`：顶部导航栏的标题「校园笔记」、背景色米白、文字黑色。
- `tabBar`：底部 4 个标签 —— 首页 / 笔记 / 校区 / 我的，每个都有普通和选中两种图标。
- `style: v2`：使用新版组件样式。

### `app.wxss` —— 全局「公共衣柜」

定义整套配色变量（`--ink` 墨蓝、`--bg` 米白、`--line` 分割线等）和公共样式类：

- `.page` 页面容器、`.card` 卡片、`.section-title` 区块标题
- `.tag` 浅色胶囊标签、`.btn-primary` / `.btn-ghost` 按钮
- `.empty` 空状态、`.divider` 分割线、`.ellipsis-2/3` 多行省略

所有页面直接复用这些类，保证风格统一。

### `project.config.json` / `project.private.config.json`

- 前者是项目的「身份证」：AppID、编译设置、是否空白模板等，**一般不要改**。
- 后者是你自己电脑上的偏好（比如模拟器设置），不影响别人。

### `sitemap.json`

告诉微信哪些页面可以被搜索到，这里设置为全部允许。

### `images/`

底部导航用的 8 张图标（4 个标签 × 普通/选中），文件名与 `app.json` 里 `iconPath` 一一对应。

## 四、六个页面逐个说明

### 1. 首页 `pages/index/`

**目标：3 秒知道能做什么。**

- 顶部：校区切换（下拉选择）、搜索、消息按钮
- 主卡片「今日打卡」：显示今天是否已打卡、打卡类型、连续天数，右侧按钮直达打卡页
- 两张小卡片：我的笔记数量 + 最近一条标题；校区活动数量 + 最近活动
- 快捷入口 5 个：打卡、记笔记、课表、二手、活动报名
- 信息流：校园动态（最近 3 条）、热门笔记（公开笔记 3 条）、今日打卡排行榜（前 5 名）
- 支持下拉刷新；每次回到首页自动刷新，打卡后状态立刻同步

**数据来源**：`checkins`、`notes`、`activities` 三个云集合。

### 2. 打卡页 `pages/checkin/`

**目标：降低操作成本，强化坚持感。**

- 顶部三个统计：连续天数、累计打卡天数、今日状态
- 5 种打卡类型：早起 🌅 / 自习 📖 / 运动 🏃 / 读书 📚 / 喝水 💧
- 中间一个**大按钮「立即打卡」**，拇指轻松点到
- 打卡成功：手机轻震动 + 全屏徽章动效（🎉 打卡成功 · 连续 N 天），1.6 秒后自动收起
- 28 天热力图：打过卡的格子颜色变深，一眼看出坚持情况
- 打卡时间线：最近 10 条记录
- 今日排行榜：按当天打卡时间先后排名（先打卡的在前），展示打卡类型

**规则**：同一天只能打一次卡，重复点击会提示「今天已经打过卡啦」。

### 3. 笔记列表页 `pages/notes/`

**目标：好找、好读、好整理。**

- 顶部搜索框：按标题或正文关键词搜索
- 标签筛选：全部 / 学习 / 生活 / 社团 / 考试 / 读书 / 美食（横向滑动）
- 视图切换：卡片视图 ▦ / 列表视图 ☰
- 笔记卡片：标题、摘要（最多 3 行）、标签、校区、作者、日期；私密笔记带「私密」角标
- 右下角悬浮「＋」按钮，随时写新笔记
- 空状态引导：「记录第一条校园笔记」

**数据规则**：列表 = 公开笔记 + 我自己的笔记（含私密），按 `_id` 去重、按时间倒序；已软删除（有 `deletedAt`）的不显示。

### 4. 笔记详情 / 编辑页 `pages/note-detail/`

**一个页面三种模式**，靠有没有带 `id` 参数区分：

**编辑模式（新建）**
- 标题输入框 + 正文输入框
- 标签多选、关联校区选择、公开/私密开关
- 工具栏：加粗 B、列表 ≡、插入图片 🖼（上传到云存储）、附件 📎
- 输入时显示「内容已暂存」提示
- 底部固定「保存」按钮，保存后自动返回列表

**详情模式（查看）**
- 标题、作者、校区、日期、标签、正文、正文图片
- 底部操作栏：点赞 👍（云端计数 +1）、收藏 ⭐（本地记录）、评论 💬（提示即将上线）、编辑 ✏️（仅本人可见）、分享

**编辑模式（修改）**
- 详情页点「编辑」进入，复用编辑表单，保存后回到详情页
- 仅笔记作者本人可编辑，越权会提示「只能编辑自己的笔记」

**校验**：标题和正文都不能为空，否则给出友好提示。

### 5. 校区页 `pages/campus/`

**目标：把「校区」做成信息枢纽。**

- 顶部插画区：校区名（可切换）、一句话介绍
- 校区概况：地址、开放时间、联系方式（点击可直接拨号）
- 常用功能 5 个：课表、空教室、活动、二手、失物招领
- 校区动态：列表 / 地图两种视图切换（地图为占位展示，先显示地址）
- 附近服务：打印店、食堂、快递点

**数据来源**：校区基础信息写在前端常量里（3 个校区），活动来自 `activities` 集合并按校区过滤。

### 6. 个人中心 `pages/mine/`

- 头像（昵称首字）、昵称、所属校区，点「编辑」可改昵称
- 数据统计：连续打卡天数、笔记数、打卡天数
- 我的：我的打卡、我的笔记、我的收藏、我的报名
- 设置：修改昵称、隐私设置、意见反馈
- 支持下拉刷新

## 五、云数据库设计（`.devtools/db.json`）

项目使用云开发数据库，共 3 个集合：

### `checkins` —— 打卡记录

| 字段 | 类型 | 说明 |
|---|---|---|
| `_openid` | String | 打卡用户，系统自动写入 |
| `type` | String | 类型：early / study / sport / read / water |
| `dateKey` | String | 日期 `YYYY-MM-DD`，用于按天去重和热力图 |
| `nickName` | String | 昵称，排行榜展示用 |
| `campus` | String | 所属校区 |
| `createdAt` | Date | 打卡时间（服务器时间） |

### `notes` —— 校园笔记

| 字段 | 类型 | 说明 |
|---|---|---|
| `_openid` | String | 作者，系统自动写入 |
| `title` / `content` | String | 标题 / 正文 |
| `tags` | Array | 标签数组 |
| `campus` | String | 关联校区 |
| `isPublic` | Bool | true 公开，false 私密 |
| `authorName` | String | 作者昵称 |
| `likeCount` | Number | 点赞数 |
| `createdAt` / `updatedAt` | Date | 创建 / 更新时间 |
| `deletedAt` | Date | 软删除时间，为空表示未删除 |

### `activities` —— 校区活动与公告

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` / `desc` | String | 活动标题 / 简介 |
| `campus` | String | 所属校区 |
| `timeText` / `place` | String | 时间文字 / 地点 |
| `createdAt` | Date | 创建时间 |

> 说明：数据库目前是空的，所以排行榜、动态、热门笔记会显示空状态提示，这是正常的。写几条笔记、打一次卡之后就有内容了。

## 六、页面之间怎么跳转

```
首页 ──┬─→ 打卡页（navigateTo）
       ├─→ 笔记列表（switchTab）
       ├─→ 校区页（switchTab）
       └─→ 笔记详情（navigateTo?id=xxx）

笔记列表 ──→ 笔记详情 / 新建笔记（navigateTo）

个人中心 ──┬─→ 打卡页
           └─→ 笔记列表（switchTab）

底部 tabBar：首页 / 笔记 / 校区 / 我的（switchTab 切换）
```

**小知识**：`switchTab` 只能跳底部标签页，`navigateTo` 用于跳普通页面。
